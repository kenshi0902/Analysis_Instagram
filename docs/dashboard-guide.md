# ダッシュボードの見方

## 設計で注意した点
- 実数ではなく「÷リーチ」の率で比べる。フォロワー数や投稿からの経過日数に左右されず、投稿の質を公平に比較できる。
- 代表値は中央値。1本のバズで平均が歪むのを防ぐ。件数nが5未満の値は薄く表示し、参考値として扱う。
- リーチは重複を除いた期間ユニーク値を使い、日次の値を足し合わせない。
- KPIには必ず前期間比を付け、良し悪しを判断できるようにした。
- 推定値や集計中の投稿は明示し、確定値と混同しないようにした。

## 効率的な見方
1. **概要**: まず「期間リーチ・リーチ率・シェア率」の前期間比を確認する。下がっていれば、ファネルでリーチ・プロフィール訪問・フォローのどこが落ちたかを見る。
2. **投稿**: 評価時点を「7日」に揃え、散布図の右上(リーチもERも中央値以上)の投稿から共通点を探す。シェア率は、フォロワー外への拡散力の目安になる。
3. **ストーリーズ**: 残存率が急に落ちる枚目を確認し、1日の投稿枚数や構成を調整する。
4. **オーディエンス**: 反応指数が1.2以上の層を、狙うべき層の候補とする。
